# Tag Pool

Canonical tags for workstream cards. One per line: `- <tag>`, lowercase, letters,
digits and hyphens only. A tag is "defined" once it is listed here — reuse the
listed spelling, including when a candidate word is only a different grammatical
form of a listed idea (e.g. a gerund or plural of an existing noun); register a new
line only when the work's subject genuinely has no covering entry. The index
generator (`fc-index.mjs`) WARNs on any workstream tag not listed here, naming the
nearest listed spelling when one is within a small edit distance — but a WARN with
no suggestion still means "not listed," not "safe to leave."
